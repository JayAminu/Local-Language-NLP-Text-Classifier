# Local-Language NLP Text Classifier

**Capstone Project** – Machine Learning text classification pipeline for regional language processing.

## Project Overview
This project implements a text classification pipeline focused on regional/local language processing. It was developed as a Computer Science capstone project at Chatham University.

The system processes and classifies text data, with particular relevance to low-resource and local language scenarios (including Hausa-English contexts).

## Technologies Used
- **Python**
- **Pandas**
- **scikit-learn**
- Natural Language Processing techniques

## Key Features
- Text preprocessing and cleaning pipeline
- Feature extraction for classification
- Model training and evaluation using scikit-learn
- Designed for regional language text data

## Skills Demonstrated
- Machine Learning pipeline development
- NLP preprocessing
- Data handling with Pandas
- Model evaluation
- Working with local/regional language datasets
